# User Manual

## Purpose
This application helps users enter symptoms and receive possible rule-based diagnoses.

## Launch
- Start the application: `python main.py`

## Steps to Use
1. Start the application.
2. Check all symptoms that apply to the case.
3. Click **Diagnose**.
4. Review results panel for:
   - Disease name
   - Confidence score
   - Matched symptoms
   - Reasoning
5. Use **Clear Selection** to reset checkboxes for a new case.
6. Optionally use **Select Respiratory Set** as a quick profile.

## Input Notes
- The interface uses checkboxes, no text typing is required.

## Important Notice
This software is for educational purposes only and is not a replacement for professional medical consultation.
